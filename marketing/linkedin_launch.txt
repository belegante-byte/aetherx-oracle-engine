Port congestion is a market signal. Most desks and logistics teams still read it too late.

Today we're launching Aether-X Port Congestion Oracle — an API that turns public port telemetry into machine-readable congestion scores, ETA delay estimates and freight volatility indices for the world's largest ports.

One HTTP call. A validated, typed payload. Ready for quants, bots and control towers.

Why it matters:
- A backup at Santos, Shanghai or Rotterdam moves freight rates and delivery SLAs within hours.
- Aether-X compresses that into a single signal: congestion_score, eta_delay_days, waiting_vessels, freight_volatility_index.
- 15 strategic global ports covered, with graceful fallback for any UN/LOCODE not yet in the dataset.
- Built on FastAPI + DuckDB, deployed on Railway, with public OpenAPI docs.

For quantitative funds and algo traders:
- Python SDK (v0.3.1), one line to install: pip install --upgrade aetherx-oracle
- Async batch mode: query an entire port portfolio in parallel and rank by risk
- Clean, validated objects — no scraping, no fragile parsing

For data engineers:
- MIT-licensed SDK, typed responses, sync + async clients
- Idempotent ingestion, DuckDB analytical engine, public OpenAPI 3.0 spec
- Predictable per-query pricing — easy to embed in a pipeline or an agent

For logistics and supply chain professionals:
- Early-warning signals to protect SLAs and re-route cargo
- Freight volatility pressure indicator to anticipate repricing
